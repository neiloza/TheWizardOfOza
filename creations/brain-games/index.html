📋 Embedding on Your Website

Each game is a self-contained HTML file. Embed any game on your website using an <iframe>: 

<iframe
  src="numbers-game.html"
  width="100%"
  height="700"
  style="border: none; border-radius: 16px; max-width: 600px;"
  title="Numbers Game"
  loading="lazy"
></iframe>

For a responsive container that adapts to the page: 

<div style="max-width: 600px; margin: 0 auto;">
  <iframe
    src="numbers-game.html"
    width="100%"
    height="700"
    style="border: 1px solid #E8DDD0;
           border-radius: 16px;
           box-shadow: 0 4px 20px rgba(0,0,0,0.08);"
    title="Numbers Game"
  ></iframe>
</div>

Reaction Game   → 750px
